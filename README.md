# C Programming & Embedded Systems Basics

This repository contains a collection of basic embedded C programming exercises focused on digital input/output, LEDs, buttons, timers, interrupts and button debouncing.

The projects were created as part of my embedded systems and low-level programming practice. They demonstrate basic hardware-oriented thinking and working with microcontroller concepts in C.

---

## Repository Content

| Folder | Topic |
|---|---|
| `01_Basic_DIO-leds` | Basic digital output using LEDs |
| `02_Basic_DIO-leds_extended` | Extended LED exercises |
| `03_Basic_DIO-buttons_using_polling` | Button handling using polling |
| `04_Basic_DIO-buttons_using_interrupts` | Button handling using interrupts |
| `05_Timers-times_wait` | Timer-based waiting |
| `06_Timers-times_execution` | Measuring execution time using timers |
| `07_Debouncing_buttons_using_timer` | Button debouncing using timers |
